HOME TV - лаунчер для Android TV в стиле tvOS

СБОРКА APK (без установки программ)
1. Создай репозиторий на github.com и загрузи туда содержимое этой папки,
   включая скрытую папку .github.
2. Вкладка Actions -> Build APK -> дождись зелёной галочки.
3. Внизу страницы скачай HomeTV-apk, распакуй app-debug.apk.
(Либо открой папку в Android Studio: Build -> Build APK.)

УСТАНОВКА (Windows)
1. На телевизоре: Настройки -> Об устройстве -> 7 раз нажать на "Сборка".
   Затем в "Для разработчиков" включить "Отладка по сети" / "Отладка USB".
2. Скачай Android platform-tools и положи в одну папку adb.exe, app-debug.apk
   и файлы .bat из этого архива.
3. Запусти 1_install.bat, введи IP телевизора (Настройки -> Сеть).

ОТКАТ: 2_restore_old_launcher.bat

ПУЛЬТ
Стрелки - фокус. ОК - открыть. Долго ОК - перемещение иконок.
Назад на верхнем ряду - пункт управления.
